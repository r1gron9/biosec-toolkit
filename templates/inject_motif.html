Inject Promoter Motif

This tool accepts as input a CSV file with DNA sequences and tests the option of inserting a promoter motif - "TATAAT" into them without changing the original protein sequence. The script's output refers both to the percentage of success, and to the success for each specific sequence using a CSV file that is downloaded as output and analyzes in which sequences the insertion attempt was successful, and in which case and location this happened for those sequences.
